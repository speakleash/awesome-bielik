# awesome-bielik

Wyselekcjonowana lista projektów, aplikacji, asystentów, narzędzi, badań i wdrożeń wykorzystujących polską rodzinę otwartych modeli językowych **Bielik**.

## Oficjalne projekty SpeakLeash

- [Chat.bielik.ai](https://chat.bielik.ai/) — oficjalny interfejs czatu (wymaga logowania).
- [Bielik Guard / Sójka](https://guard.bielik.ai/) — detekcja treści szkodliwych.
- [Obywatel Bielik](https://obywatel.bielik.ai/) — zbiór zdjęć i opisów polskiego dziedzictwa.
- [Eskadra Bielika](https://eskadra.bielik.ai/) — budowa agentów i RAG w społecznościach.
- [Bielik Nest Builders](https://www.beyond.pl/baza-wiedzy/webinary-i-wydarzenia/bielik-nest-builders-warsztaty-technologiczne/) — budowanie i orkiestracja agentów.
- [Bielik Arena / Chat Arena PL](https://arena.speakleash.org.pl/) — porównywanie modeli językowych.
- [Bielik Tools](https://github.com/speakleash/bielik-tools) — structured output, tool calling, reasoning, multi-agent.
- [Bielik Papers](https://github.com/speakleash/bielik-papers) — raporty techniczne i artykuły naukowe.
- [Bielik How to Start](https://github.com/speakleash/Bielik-how-to-start) — 17+ przykładów użycia.
- [Bielik Prompt Book](https://github.com/speakleash/bielik-prompt-book) — prompty z różnych domen.
- [SpeakLeash Instruct Creator](https://github.com/speakleash/speakleash-instruct-creator) — generowanie datasetów instruktażowych do fine-tuningu.
- [Multimodal Data Generation](https://github.com/speakleash/multimodal-data-generation) — syntetyczne dane wizualne/audialne/tekstowe.
- [Eskadra Bielik - Misja 1](https://github.com/speakleash/eskadra-bielik-misja1) — systemy agentowe, RAG, culinary guide, content creator.
- [Nvidia Bielik Minitron Livestream](https://github.com/speakleash/nvidia-bielik-minitron-livestream) — przykłady NVIDIA × Bielik.
- [Bielik Tokenizers](https://huggingface.co/spaces/speakleash/bielik-tokenizers) — Playground do analizy tokenizacji, słownika i chat template modeli Bielika.
